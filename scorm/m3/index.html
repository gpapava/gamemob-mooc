The brief

    Assumptions behind the numbers
    • Per pupil-km, rounded: car with one pupil 170 g, car shared by three pupils 57 g, bus 70 g, e-scooter or bike 0 g, walking 0 g. These are order-of-magnitude values in line with published averages (e.g. EEA, UK DEFRA); a real project should use its own agreed factors.
    • Only the journey to school is counted, once each way, 180 school days. The empty return trip of a parent's car is ignored, which flatters cars.
    • Average distance per group: 0.6 km, 2 km, 4.5 km. Only operating emissions, no manufacturing or road building.
    • Walking is not offered over 3 km. A bus lane or a safe bike route has to exist before a pupil can use it, which is a module 4 problem.
